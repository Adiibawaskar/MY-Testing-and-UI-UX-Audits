# 🛒 QA Testing & UI/UX Audit Portfolio

A comprehensive Quality Assurance and UI/UX testing repository documenting visual glitches, layout responsiveness breakdowns, and alignment inconsistencies across major digital platforms.

---

## 📌 Portfolio Overview

This repository showcases real-world exploratory testing, visual QA audits, and structured defect documentation following industry-standard bug reporting formats (similar to JIRA/Linear ticketing systems).

### 🛠️ Key Audit Focus Areas
* **Visual Hierarchy & Alignment:** Identifying spacing anomalies, unstyled elements, and typography glitches.
* **Layout Responsiveness:** Auditing grid reflows, overflow issues, and breakpoint failures across device viewports.
* **Content Usability:** Documenting premature text truncation, unreadable labels, and touch target accessibility issues.
